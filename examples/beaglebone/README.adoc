== Überblick

Demonstriert wie ein *BeagleBone Black* (BME280-Sensor, GPIO) über den UDAL HTTP Adapter als reguläres UDAL-Device exponiert wird — ohne eine einzige Code-Änderung im link:https://github.com/paul-fleischmann-com/beaglebone_black[beaglebone_black-Repo].

[cols="1,3"]
|===
| Weg | HTTP Adapter (Polling) — Weg 1 aus #45
| UDAL-Version | v1.0.0
| BeagleBone IP | `192.168.7.2:5000` (USB-OTG Standard)
| Poll-Intervall | 5 s (konfigurierbar)
|===

.Architektur
....
BeagleBone Black          UDAL Gateway         Client
:5000 REST API   <---->   HTTP Adapter  <---->  gRPC :50051
BME280 · GPIO             pollt :5000           REST :8080
....

== UDAL Gateway starten

WARNING: `--dev` deaktiviert TLS — nur für lokale Demo-Umgebungen. In Produktion TLS + API-Key verwenden.

.Binary
[source,bash]
----
./udal-gateway \
  --dev \
  --bootstrap-api-key demo-key-123 \
  --grpc-addr :50051 \
  --http-addr :8080 \
  --metrics-addr :9090
----

.Docker
[source,bash]
----
docker run --rm \
  -p 50051:50051 -p 8080:8080 -p 9090:9090 \
  -e UDAL_DEV_INSECURE=true \
  -e UDAL_BOOTSTRAP_API_KEY=demo-key-123 \
  ghcr.io/paul-fleischmann-com/udal:1.0.0
----

.Gateway-Health prüfen
[source,bash]
----
curl http://localhost:9090/health
# → {"status":"ready"}
----

== Capability-Schema anlegen

Das Schema beschreibt welche Properties das BeagleBone-Device hat.
Es wird beim Gateway registriert bevor das Device angemeldet werden kann.

.beaglebone-bme280.schema.json
[source,json]
----
{
  "name":        "beaglebone-bme280",
  "version":     "1.0",
  "description": "BeagleBone Black — BME280 Sensor + GPIO",
  "properties": {
    "temperature": {
      "type":     "float",
      "unit":     "°C",
      "readable": true,
      "writable": false
    },
    "humidity": {
      "type":     "float",
      "unit":     "%rH",
      "readable": true,
      "writable": false
    },
    "pressure": {
      "type":     "float",
      "unit":     "hPa",
      "readable": true,
      "writable": false
    },
    "gpio_usr0": {
      "type":        "int",
      "description": "USR0 LED (GPIO 60)",
      "readable":    true,
      "writable":    true
    }
  }
}
----

.Schema beim Gateway registrieren
[source,bash]
----
curl -X POST http://localhost:8080/api/v1/capabilities \
  -H "Authorization: Bearer demo-key-123" \
  -H "Content-Type: application/json" \
  -d @beaglebone-bme280.schema.json
----

== Device registrieren

Der HTTP Adapter benötigt eine `transport_config` mit der Base-URL der BeagleBone-API und einem Poll-Intervall pro Property.

[source,bash]
----
curl -X POST http://localhost:8080/api/v1/devices \
  -H "Authorization: Bearer demo-key-123" \
  -H "Content-Type: application/json" \
  -d '{
    "name":       "beaglebone-01",
    "capability": "beaglebone-bme280@1.0",
    "transport":  "http",
    "transport_config": {
      "base_url":      "http://192.168.7.2:5000",
      "poll_interval": "5s",
      "endpoints": {
        "temperature": "/api/v1/bme280",
        "humidity":    "/api/v1/bme280",
        "pressure":    "/api/v1/bme280",
        "gpio_usr0":   "/api/v1/gpio/60"
      },
      "json_paths": {
        "temperature": "$.temperature",
        "humidity":    "$.humidity",
        "pressure":    "$.pressure",
        "gpio_usr0":   "$.value"
      }
    },
    "labels": {
      "location": "desk",
      "hw":       "beaglebone-black"
    }
  }'
----

.Device-Liste prüfen
[source,bash]
----
curl http://localhost:8080/api/v1/devices \
  -H "Authorization: Bearer demo-key-123"
----

TIP: Mit `grpcurl` alternativ über gRPC: +
`grpcurl -plaintext -d '{"name":"beaglebone-01",...}' localhost:50051 udal.v1.DeviceService/RegisterDevice`

=== Python SDK

[source,bash]
----
pip install udal-sdk
----

[source,python]
----
import asyncio
from udal import UDALClient

async def main():
    async with UDALClient(
        "localhost:50051",
        api_key="demo-key-123",
        insecure=True
    ) as client:
        temp = await client.get_property("beaglebone-01", "temperature")
        print(f"Temperatur: {temp.value}°C")

asyncio.run(main())
----

== Live-Streaming (Subscribe)

Property-Updates in Echtzeit empfangen — Gateway pollt BBB alle 5 s und pusht Änderungen.

[source,python]
----
async def stream():
    async with UDALClient("localhost:50051", api_key="demo-key-123", insecure=True) as c:
        async for update in c.subscribe("beaglebone-01", "temperature"):
            print(f"[{update.timestamp}] {update.value:.2f}°C")

asyncio.run(stream())
----

[source,bash]
----
# grpcurl
grpcurl -plaintext \
  -H "authorization: Bearer demo-key-123" \
  -d '{"device_id":"beaglebone-01","property_path":"temperature"}' \
  localhost:50051 udal.v1.DeviceService/SubscribeProperty
----

== GPIO schreiben (optional)

USR0-LED am BeagleBone über UDAL `SetProperty` ein-/ausschalten.

[source,bash]
----
# LED einschalten
curl -X PUT \
  "http://localhost:8080/api/v1/devices/beaglebone-01/properties/gpio_usr0" \
  -H "Authorization: Bearer demo-key-123" \
  -H "Content-Type: application/json" \
  -d '{"value": 1}'
----

[source,python]
----
# LED blinken lassen
for _ in range(5):
    await client.set_property("beaglebone-01", "gpio_usr0", 1)
    await asyncio.sleep(0.5)
    await client.set_property("beaglebone-01", "gpio_usr0", 0)
    await asyncio.sleep(0.5)
----
